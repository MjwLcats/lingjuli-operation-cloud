# Lingjuli Operation Cloud

面向餐饮集团、区域、门店与员工的多租户 SaaS 运营平台。

## Repository

- `apps/lingjuli-web-platform`: SaaS 平台管理端
- `apps/lingjuli-web-merchant`: 商家管理端
- `apps/lingjuli-mobile`: uni-app x 移动执行端
- `packages`: Design Token、Web UI、API 客户端等共享包
- `backend`: Java 17 / Spring Cloud 多服务后端
- `docs`: 架构、研发和业务规范

开始开发前必须阅读 [AGENTS.md](AGENTS.md) 与 [项目总览](docs/00-project-overview.md)。
